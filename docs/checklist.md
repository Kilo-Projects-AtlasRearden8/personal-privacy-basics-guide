# Printable privacy checklist

Print this page and check off each item as you do it. You do not have to finish it all at once — do a little at a time.

Every example in this guide uses made-up names, emails, phone numbers, and addresses.

## Accounts

- [ ] Password manager installed
- [ ] Strong, unique password on email
- [ ] Strong, unique password on banking
- [ ] Strong, unique password on password manager
- [ ] 2FA turned on for email (authenticator app preferred)
- [ ] 2FA turned on for banking
- [ ] 2FA turned on for password manager
- [ ] Backup codes saved (printed or on paper)
- [ ] Old devices signed out of important accounts
- [ ] Unused connected apps removed
- [ ] Social media profiles set to private / limited
- [ ] Security question answers made up and saved
- [ ] Breach check run for my email address

## Browser

- [ ] Tracking protection turned on (Strict or Balanced)
- [ ] Ad/tracker blocker installed (e.g., uBlock Origin)
- [ ] Third-party cookies blocked
- [ ] Browser set to clear cookies and history (or clear automatically)
- [ ] Private browsing used when needed
- [ ] Browser sync protected with strong password + 2FA (if used)
- [ ] Browser updates turned on automatically

## Phone

- [ ] Screen lock: 6+ digit passcode or alphanumeric passcode
- [ ] Auto-lock: 30 seconds to 2 minutes
- [ ] Find My iPhone / Find My Device turned on
- [ ] App permissions reviewed (location, contacts, camera, microphone)
- [ ] Phone OS updates automatic
- [ ] App updates automatic
- [ ] Public Wi-Fi avoided for banking/shopping (or VPN used)
- [ ] Ad tracking limited / advertising ID reset
- [ ] Remote erase set up
- [ ] Phone backed up

## AI training opt-outs

- [ ] ChatGPT training turned off
- [ ] Claude training turned off
- [ ] Gemini activity turned off or auto-delete set
- [ ] Copilot training turned off
- [ ] Meta AI objection submitted (if available in your region)
- [ ] Other AI tools checked
- [ ] Rule adopted: never paste passwords, financial info, health details, or others' private data into AI tools

## Data brokers

- [ ] Searched my name + city; found people-search listings
- [ ] Private list made of sites, URLs, and dates
- [ ] Opt-out requests sent to each site
- [ ] Email confirmations clicked where required
- [ ] "Do Not Sell My Personal Information" used (if my state has it)
- [ ] Calendar reminder set to re-check in 3–6 months

## Scam awareness

- [ ] I do not click links in unexpected emails/texts
- [ ] I never give passwords or 2FA codes to anyone
- [ ] I do not pay with gift cards, wire, or crypto on someone's say-so
- [ ] I verify urgent requests through a separate channel
- [ ] I know how to report spam and phishing
- [ ] I know where to report fraud (reportfraud.ftc.gov in the US)
