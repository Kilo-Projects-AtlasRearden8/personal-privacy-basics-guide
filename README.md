# Personal Privacy Basics

A beginner-friendly manual on locking down your accounts, browsers, and phones — plus how to opt out of AI training and data brokers, and how to spot scams. Plain English, step by step, never condescending. Includes a printable checklist.

Written and published by **Asdale Dynamics, LLC** — beginner-friendly AI education, books, and guides.

## What's inside

- `docs/` — the manual in Markdown (one chapter per topic, plus a printable checklist)
- `static/` — a self-contained HTML version of the manual, one file per chapter, with a shared stylesheet
- `STATUS.md` — what was built, how to run it, and verification results

## Chapters

1. [Locking down your accounts](docs/01-accounts.md)
2. [Locking down your browser](docs/02-browsers.md)
3. [Locking down your phone](docs/03-phones.md)
4. [Opting out of AI training](docs/04-ai-training.md)
5. [Opting out of data brokers](docs/05-data-brokers.md)
6. [Spotting scams](docs/06-scams.md)
7. [Printable privacy checklist](docs/checklist.md)

## How to read it

- **Markdown:** open any file in `docs/` with a text editor or Markdown reader.
- **HTML:** open any file in `static/` directly in your web browser. No build step, no internet connection required after you have the files.
- **Print:** use your browser's Print command on `static/checklist.html` (or `docs/checklist.md`) to get a one-page checklist you can check off by hand.

## Example data

Every name, email, phone number, and address in this guide is made up. Never copy real personal information into examples, and never share your own real details when practicing these steps.
